# Security Policy

opencode-swap is discontinued, and no version receives fixes. 0.4.7 (the CLI and the OpenCode 1
TUI plugin) is the last release that handles credentials; 1.x on npm is only a notice and reads
none.

If you find a vulnerability in 0.4.7 that affects people still using it, report it privately
anyway, so it can at least be documented: use
[GitHub's private vulnerability reporting](https://github.com/leinardi/opencode-swap/security/advisories/new),
or email `roberto@leinardi.com`. **Never include credentials, tokens, `auth.json` or
`opencode auth export` output in a report.**
